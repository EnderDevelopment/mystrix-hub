# Mystrix Hub

Mystrix Hub is a Minecraft plugin designed to enhance the hub experience with custom commands and features. It provides a simple yet effective way to add personalized interactions and commands to your Minecraft server hub.

## Install

1. Download the Mystrix Hub plugin JAR file from the releases section.
2. Place the JAR file into the `plugins` folder of your Minecraft server.
3. Restart or reload your server to load the plugin.

## Use

1. Once the server is running with the plugin installed, you can use the custom commands provided by Mystrix Hub.
2. For example, type `/ciao` in the chat to greet yourself.
